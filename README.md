# YANLIŞ HESAP MAKİNESİ

## Resmi ve Son Derece Ciddi Proje Dokümantasyonu

Bu repository, insanlığın matematik alanındaki en büyük hatasını düzeltmek (veya daha da büyütmek) amacıyla kurulmuştur. Klasik hesap makineleri "doğru" sonuçlar vermeye çalışırken, **Yanlış Hesap Makinesi** bilerek, isteyerek ve gururla yanlış sonuçlar üretir.

### Neden Bu Proje Var?

Çünkü:
- Doğru cevaplar sıkıcıdır.
- Matematik fazla kibirli davranıyordu.
- Birisi "2+2=4" diyene kadar kimse "neden?" diye sormuyordu.
- Evrenin kendisi de bazen yanlış hesap yapıyor olabilir (kara delikler, kuantum falan).

### Özellikler

- **%100 Yanlışlık Garantisi**: Her işlem sonucunda doğru cevabı bilerek reddeder.
- **Felsefi Açıklamalar**: Sadece sayı vermez, neden yanlış olduğunu da şiirsel dille anlatır.
- **Kuantum Bekleme Sistemi**: Hesaplama sırasında abartılı loading mesajları gösterir.
- **Rastgele Absürtlük Motoru**: Sonuçlar tamamen öngörülemezdir (ama her zaman yanlıştır).
- **Sıfır Bağımlılık**: Sadece Python standart kütüphanesi kullanır. Dış dünya ile ilişki kurmaz.

### Kurulum

```bash
git clone https://github.com/Tentivory/yanlis-hesap-makinesi.git
cd yanlis-hesap-makinesi
python3 yanlis_hesap.py
```

Başka hiçbir şey gerekmez. Hatta Python bile gerekmeyebilir, ama o zaman çalışmaz.

### Kullanım Örneği

```
Birinci sayı: 5
İkinci sayı: 3
İşlem (+, -, *, /): +

Hesaplanıyor... (kuantum dalgalanmaları dikkate alınıyor)
Evrenin entropisi kontrol ediliyor...
Sonuç neredeyse hazır...

Sonuç: 42

Neden mi? Çünkü klasik matematik burjuva bir yapıdır ve gerçek özgürlüğü kısıtlar.
```

### Uyarılar

- Bu yazılım hiçbir bilimsel, ticari, akademik veya evlilik davasında kullanılmamalıdır.
